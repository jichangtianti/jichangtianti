## 💡 科学上网高频避坑 FAQ

<details>
<summary><b>Q1: 为什么有时候节点 Ping 得通但打不开网页？</b></summary>
ICMP Ping 只能说明中转入口服务器可达，不代表落地机与目标网站之间的隧道握手成功。遇到此情况请检查客户端的 DNS 配置或切换落地节点。
</details>

<details>
<summary><b>Q2: 为什么使用机场节点访问 ChatGPT 会被拒或提示 IP 限制？</b></summary>
OpenAI 会对机房数据中心（Datacenter）IP 进行严格风控。建议在客户端中选择标有“原生/家宽/Residential”字样的落地节点。
</details>

<details>
<summary><b>Q3: IPLC 专线和普通公网中转有什么本质区别？</b></summary>
IPLC/IEPL 走的是物理内网光纤跨境外，不过公网防火墙，晚高峰不受国际骨干网拥堵影响；普通中转走公网隧道，敏感时期易受干扰和限速。
</details>
